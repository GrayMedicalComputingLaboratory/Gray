Gray API Reference

Gray Medical Computing Laboratory 的可复用训练研究框架 API。本文档对应当前 main 分支，说明输入、输出、异常和典型调用方式。

目录 安装与约定 配置与 CLI Utils 通用指标 临床二分类 TTA DICOM / SimpleITK Optuna 边界

安装与约定

Gray 不包含项目专用模型、数据集和训练循环。项目通过 entrypoint 接入 Gray。

python -m pip install --upgrade "git+ssh://git@github.com/GrayMedicalComputingLaboratory/Gray.git@main"
每个实验只维护一个 YAML；YAML 文件名就是 experiment_id。生成的 trial 配置只是运行快照，不是第二份人工配置。

配置与 CLI

gray.core.config.load_config

load_config(path, overrides=()) -> tuple[dict, Path]

输入path：单个 YAML 路径；overrides：Hydra 风格的 key=value 列表。
输出解析后的普通字典和绝对配置路径；自动加入 experiment_id、_config_dir。
限制不允许 defaults、配置组或自动切换工作目录。
python -m gray.cli train --config configs/exp_00.yaml
python -m gray.cli train --config configs/exp_00.yaml --override train.lr=0.00003
python -m gray.cli tune --config configs/exp_00.yaml

train 在 optuna.enabled: true 时自动搜索；tune 强制搜索。项目 entrypoint 需返回字典。

gray.core.config.resolve_path

resolve_path(config, value) -> Path

Parametersconfig 必须包含 _config_dir；相对路径从 YAML 所在目录解析，绝不依赖当前工作目录。
Returns绝对路径；传入绝对路径时保持其语义。

gray.core.config.artifact_dir

artifact_dir(config, stage, create=False) -> Path

Parametersstage 只能是相对单级目录名，不能为空、绝对路径或包含 ..；create=True 时创建目录。
Returnsoutput_root / experiment_id / stage。
Raises非法 stage 时抛出 ValueError。

gray.core.device.resolve_device

resolve_device(value: str | int) -> str

Accepted"cpu"、"cuda"、"cuda:N" 或非负 GPU 索引。
Returns规范化设备名，例如 cuda:0。
Raises设备格式错误抛出 ValueError；请求的 CUDA 不存在抛出 RuntimeError，不会静默回退 CPU。

gray.core.provenance.sha256 / model_manifest

sha256(path: Path) -> str
model_manifest(config, checkpoint: Path) -> dict

前者以流式方式计算文件哈希；后者记录实验、模型版本、数据版本、标签 schema、随机种子、fold、配置哈希、Git commit 和 checkpoint 哈希，适合随模型一同归档。

Utils

gray.utils.seed_everything

seed_everything(seed, deterministic=True) -> None

固定 Python、Hash、NumPy、PyTorch、CUDA 和 cuDNN 随机状态。deterministic=True 会关闭 cuDNN benchmark。

gray.utils.seed_worker

seed_worker(worker_id) -> None

用于 PyTorch DataLoader(worker_init_fn=...)，根据 worker seed 固定 Python 与 NumPy。

gray.utils.torch_generator

torch_generator(seed) -> torch.Generator

返回可传给 DataLoader(generator=...) 的 PyTorch Generator。

gray.utils.tta

tta(sample, *, dim, horizontal_flip=False, vertical_flip=False, rotate90_angles=(0,)) -> dict

支持 NumPy 与 PyTorch；dim="2d" 或 "3d"。3D 只对最后两个 H/W 轴变换，不翻转 Z 轴。

通用指标

每项指标均可独立导入；classification_metrics 只负责组合。

输入约定与失败行为

averagemacro 对每类等权；weighted 按 support 加权；不支持的值会抛出 ValueError。

临床二分类

clinical_binary_metrics

clinical_binary_metrics(targets, predictions, probabilities, positive_label=None, n_bins=10, n_bootstrap=2000, confidence=0.95, seed=42, thresholds=None) -> dict

组合 Sensitivity、Specificity、PPV、NPV、ROC-AUC、PR-AUC、ECE、Brier、bootstrap CI 和阈值报告。

目标与预测必须同时包含两个类别；单类 fold 使用通用指标。

clinical_binary_metrics 返回结构

Prevalencepositive_label、negative_label、samples、positive_prevalence。
Point estimatesaccuracy、sensitivity、specificity、ppv、npv、roc_auc、pr_auc。
Uncertaintyconfidence_intervals 对上述主要指标提供 percentile bootstrap 的 estimate / lower / upper / valid_bootstrap。
Calibrationcalibration.points 是绘图数据，另含 ECE 与 Brier score。
Thresholdsthreshold_report 逐阈值提供 Sensitivity、Specificity、PPV、NPV、F1 和 Youden J。

calibration_curve

输出 points、ece 和 brier_score，points 可直接用于绘图。

bootstrap_ci

bootstrap_ci(targets, values, metric, n_bootstrap=2000, confidence=0.95, seed=42) -> dict。返回 estimate、lower、upper 和有效 bootstrap 数。

threshold_report

输出每个阈值的 Sensitivity、Specificity、PPV、NPV、F1、Youden J，并返回 Youden/F1 最优点。

variants = tta(volume, dim="3d", horizontal_flip=True,

logits = [model(value) for value in variants.values()]

DICOM / SimpleITK

当前只使用 SimpleITK；不处理患者 metadata、Series 发现或 Series 选择。

函数输入输出
read_series项目已排序的 DICOM 路径列表sitk.Image
get_spacingsitk.Image正浮点 spacing 元组
apply_rescalesitk.Image应用 Slope/Intercept 后的 Image
apply_window_levelImage、window_width、window_center映射到指定输出范围的 Image
apply_monochromeImage、MONOCHROME1/2?极性统一后的 Image
resample_volumeImage、target_spacing、interpolator重采样后的 Image
mask/label 使用 interpolator="nearest"；如果上游已经完成 rescale，不要重复调用 apply_rescale。

推荐处理顺序

image = read_series(ordered_paths)
image = apply_rescale(image)              # stored -> physical units
image = apply_monochrome(image)           # MONOCHROME1 -> 2
image = apply_window_level(image, 400, 40)
image = resample_volume(image, (1.0, 1.0, 1.0))
read_series要求调用方已经完成 Series 选择和文件排序；空列表或缺失文件会抛出异常。
apply_rescale从 tags 0028|1053 / 0028|1052 读取 slope/intercept，slope 为 0 时拒绝处理。
apply_window_levellower=center-width/2、upper=center+width/2，再映射到 [output_min, output_max]。
resample_volume支持 nearest、linear、bspline；保持 origin 和 direction，并按物理范围计算新尺寸。

Optuna 只搜索参数，不替代你的训练循环。最终模型必须用最佳参数重新训练，并单独记录最终结果。

search_space 支持类型

floatlow、high，可选 log、step。
intlow、high，可选 log、step。
categorical非空 choices 列表。
Artifactsoptuna/study.db、每个 trial 的 YAML/JSON、best_params.yaml 和 study_summary.json。
train_once必须返回字典；objective_key 用点号路径提取，例如 valid.f1_macro。可选接收 trial 进行 pruning。

边界

Gray 不提供通用 Web、模型、Dataset、loss、推理服务、患者 metadata 策略、Series 选择、DICOM 编码、临床标签规则。项目级语义必须留在项目仓库。
