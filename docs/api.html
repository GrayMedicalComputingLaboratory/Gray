Gray API Reference

Gray Medical Computing Laboratory 的可复用训练研究框架 API。本文档对应当前 main 分支，说明输入、输出、异常和典型调用方式。

安装与约定

Gray 不包含项目专用模型、数据集和训练循环。项目通过 entrypoint 接入 Gray。

python -m pip install --upgrade \
  "gray @ git+ssh://git@github.com/GrayMedicalComputingLaboratory/Gray.git@main#subdirectory=source/gray"

# Local editable installation
python -m pip install -e /path/to/Gray/source/gray

# ClearML + native nnU-Net v2
python -m pip install -e "/path/to/Gray/source/gray[train]"
每个实验只维护一个 YAML；YAML 文件名就是 experiment_id。生成的 trial 配置只是运行快照，不是第二份人工配置。

类型速查 / Type guide

标记含义典型值
PathLike字符串或 pathlib.Path 文件路径。"configs/exp_00.yaml"
Sequence[T]列表、元组或其他可迭代序列；除非特别说明，不接受空序列。["BCC", "Non-BCC"]
ArrayLikeNumPy 数组或可转换为数组的实数序列。np.ndarray、list[float]
torch.TensorPyTorch 张量；TTA 保留 dtype、device 和梯度语义。[C,H,W] 或 [C,D,H,W]

配置与 CLI

gray.core.config.load_config

load_config(path, overrides=()) -> dict

输入path：单个 YAML 路径；overrides：Hydra 风格的 key=value 列表。
输出解析后的普通字典；自动加入 experiment_id、内部配置来源 _config_path 和 _config_dir。
限制不允许 defaults、配置组、保留内部字段或自动切换工作目录。
python -m gray.cli train --config configs/exp_00.yaml
python -m gray.cli train --config configs/exp_00.yaml --override train.lr=0.00003

项目 entrypoint 需返回字典，Gray 将其写入对应 stage 的 summary.json。

gray.core.config.resolve_path

resolve_path(config, value) -> Path

Parametersconfig 必须包含 _config_dir；相对路径从 YAML 所在目录解析，绝不依赖当前工作目录。
Returns绝对路径；传入绝对路径时保持其语义。

ClearML Task

以 ClearML Task 和 OutputModel 作为实验、配置、代码、指标与模型的唯一追溯来源。

gray.experiment.init_task

init_task(config, logger=None) -> clearml.Task

必填配置experiment_id 和 tracking.project_name；tags/output_uri 可选。
功能调用 Task.init()，连接 resolved config，并在提供 logger 时将 ClearML tracker 绑定到 GrayLogger。
调用方职责日志、scalar 和 debug sample 使用 GrayLogger；参数、产物和模型使用 task.connect()、task.upload_artifact()、task.update_output_model()。
状态ClearML 在正常进程退出时标记完成，在未捕获异常时标记失败。被业务代码捕获并吞掉的异常必须由调用方自行设置状态。
不再包装Gray 不提供 run 生命周期，不规定训练返回值、checkpoint/evaluation 结构或 metadata 策略。

gray.experiment.artifact_dir

artifact_dir(config, stage, create=False) -> Path

统一生成 output_root / experiment_id / stage；stage 必须是安全的单级目录名。

from gray import load_config
from gray.experiment import artifact_dir, init_task
from gray.utils.logging import get_logger

config = load_config("configs/exp_001.yaml")
logger = get_logger("training", artifact_dir(config, "train"))
task = init_task(config, logger=logger)
result = train(config, task)

Callbacks

训练流程中的状态型回调。回调只维护自身状态，不负责模型或 checkpoint 文件写入。

gray.callbacks.EarlyStopping

EarlyStopping(patience=5, mode="min", min_delta=0.0)

输入patience：允许连续不提升的步数；mode："min" 或 "max"；min_delta：最小有效提升幅度。
调用每次验证后调用 step(metric)；返回 True 时停止训练。reset() 可重新开始一轮监控。
状态state_dict() 返回可序列化状态；load_state_dict(state) 支持断点恢复。
异常参数不合法或指标不是有限数值时抛出 TypeError / ValueError。
from gray.callbacks import EarlyStopping

early_stopping = EarlyStopping(patience=5, mode="min")
for epoch in range(epochs):
    validation_loss = validate(...)
    if early_stopping.step(validation_loss):
        break

Inference

推理结果的通用后处理；不负责模型加载或前向计算。

gray.inference.Ensemble

Ensemble(*probabilities, method="mean", weights=None) -> np.ndarray

输入每个模型概率作为一个独立位置参数。二分类形状为 [n_samples]，多分类为 [n_samples, n_classes]；单模型直接传一个数组。
方法method="mean" 使用等权平均；method="weighted" 必须传入非负、有限且数量与模型一致的 weights。
输出与单个模型输出形状相同的 numpy.ndarray 概率。
限制只接收范围为 [0, 1] 的概率，不接收 logits；多分类每行概率和必须为 1。
from gray.inference import Ensemble

probabilities = Ensemble(
    model_a_probabilities,
    model_b_probabilities,
    method="weighted",
    weights=[0.6, 0.4],
)

Preprocess

无状态的 NumPy 图像预处理操作。

gray.preprocess.remove_background

remove_background(image, *, background_colors=0, tolerance=0.0, spatial_axes=(-2, -1)) -> np.ndarray

输入数值 NumPy 兼容数组。默认裁剪最后两个 H/W 轴，适用于 H,W、C,H,W 和 B,C,H,W。
背景background_colors 可传一个或多个灰度值/颜色向量；tolerance 用于忽略颜色误差。
体数据三维体数据使用 spatial_axes=(0, 1, 2) 裁剪全部体素轴。
输出包含前景的最小边界框视图；全为背景输入保持原数组和原形状。
from gray.preprocess import remove_background

cropped_image = remove_background(image, background_colors=[0, 255], tolerance=4)
cropped_volume = remove_background(volume, background_colors=0, spatial_axes=(0, 1, 2))

Runtime

设备选择和训练可复现性控制。

gray.runtime.resolve_device

resolve_device(value: str | int) -> str

接受 cpu、cuda、cuda:N 或 GPU 索引；设备不可用时明确失败。

gray.runtime.seed_everything

seed_everything(seed, deterministic=True) -> None

固定 Python、NumPy、PyTorch、CUDA 与 cuDNN 状态。

gray.runtime.seed_worker / torch_generator

Native nnU-Net v2

Gray 只负责以统一配置、路径、设备和 logger 驱动官方 nnU-Net v2 CLI；数据转换、标签语义、后处理和临床指标由项目负责。

gray.nnunet.NnUNetRunner

NnUNetRunner(config, logger, device=None)

输入config 必须包含 nnU-Net dataset、training 和 inference 配置；logger 必须提供 GrayLogger-compatible info() 与 metric()；device 接受 CPU 或 CUDA 标识。
plan_and_preprocess调用官方 nnUNetv2_plan_and_preprocess -d DATASET_ID；默认校验 dataset integrity。
train调用官方 nnUNetv2_train；所有 stdout/stderr 逐行进入 Gray logger，并解析 loss、pseudo Dice、learning rate 和 epoch time。
predict调用官方 nnUNetv2_predict；输出目录必须尚不存在；worker 数必须为正整数。
异常CLI 不存在、命令非零退出、设备不可用、配置缺失或输出目录已存在时明确失败；命令失败包含最近 20 行输出。

gray.nnunet.NnUNetRunner.validate_checkpoint

validate_checkpoint(expected_sha256=None) -> Path

功能定位固定 split 的 checkpoint，并使用 Gray SHA-256 工具验证注册摘要。
异常摘要不是 64 位 SHA-256、checkpoint 不存在或哈希不一致时抛出异常。

gray.nnunet.dataset_dir / model_dir / nnunet_environment

生成 experiment-scoped nnUNet_raw、nnUNet_preprocessed、nnUNet_results 路径与子进程环境；不会修改当前进程的环境变量。

gray.nnunet.NnUNetLogReporter

consume(line) / close()

解析原生 nnU-Net epoch 文本，并通过 GrayLogger.metric() 上报 Loss、Pseudo Dice、Learning Rate 和 Epoch Time 图表。

from gray.nnunet import NnUNetRunner
from gray.utils.logging import get_logger

logger = get_logger("training", output_dir)
runner = NnUNetRunner(config, logger, device="cuda:0")
runner.plan_and_preprocess()
runner.train(class_names=["fetal_head"])
runner.validate_checkpoint()

Utils

gray.utils.logging.get_logger

get_logger(name: str, output_dir: Path, *, tracker=None) -> GrayLogger

输入str logger 名称；pathlib.Path 输出目录；可选 ClearML-compatible tracker。
输出GrayLogger；写入 Rich console 和 output_dir/run.log，不向 root logger 传播。
语义方法success(message)、metric(name, value, iteration=0, title="Metrics") 和 debug_sample(title, series, local_path, iteration=0, max_image_history=5)。
实验跟踪init_task(config, logger=logger) 自动绑定 ClearML logger；文本、scalar 和 diagnostic image 均通过 GrayLogger 上报。
异常metric 名称、数值、iteration 或 title 无效时失败；debug sample 文件不存在或 tracker 不支持 report_image 时失败。
文件日志只写纯文本，不包含 Rich 颜色或样式标签。

gray.utils.logging.GrayLogger.bind_tracker

bind_tracker(tracker) -> None

运行时绑定提供 report_text() 与 report_scalar() 的 tracker；ClearML Task 初始化使用该接口。

from gray.utils.logging import get_logger

logger = get_logger("train", output_dir)
logger.success("训练完成")
logger.metric("validation_auc", 0.921)
logger.debug_sample("Validation", "case_001", "debug/case_001.png")
logger.warning("数据量不足")
logger.error("checkpoint 保存失败")

gray.utils.io.write_json / read_json

write_json(path, value) -> None / read_json(path) -> dict[str, Any]

输入JSON 文件路径；写入值必须是可 JSON 序列化的 mapping。
输出write_json 自动创建父目录并原子替换文件；read_json 返回对象根字典，格式无效或根类型错误时抛出 ValueError。

gray.utils.hashing.sha256

sha256(path) -> str

以流式方式计算文件 SHA-256，不一次性加载整个文件。

variants = tta(volume, dim="3d", horizontal_flip=True,

DICOM / pydicom

pydicom 负责读取和像素解码，NumPy/SciPy 负责体数据运算；不处理患者 metadata 策略、Series 发现或 Series 选择。

函数输入输出源码
read_seriesSequence[str | Path]ndarray，shape 为 (z,y,x)Source ↗
get_spacingSequence[str | Path](slice, row, column) spacingSource ↗
apply_rescale_slope_interceptArrayLike、slope、interceptfloat64 modality valuesSource ↗
apply_window_levelArrayLike、float width/center/rangefloat32 ndarraySource ↗
apply_monochromeArrayLike、str interpretationMONOCHROME2 极性的 ndarraySource ↗
resample_volumeArrayLike、source/target spacing、interpolatorndarray；nearest 保持 dtype，linear/bspline 为 float32Source ↗

DICOM 函数契约

函数支持输入输出与约束
read_seriesSequence[str | Path]，已经选择且排序的单帧 DICOM 文件。ndarray；显式应用 Modality LUT 或 Rescale Slope/Intercept；校验 shape、PixelSpacing、Series UID 和均匀 slice spacing。
get_spacing同一组有序 DICOM 路径。(slice, row, column)；只读 header，不解码像素。
apply_rescale_slope_interceptArrayLike、slope、intercept。float64 ndarray；执行 pixels * slope + intercept。
apply_monochromeArrayLike、MONOCHROME1/2。ndarray；规范为 MONOCHROME2 极性并保持 dtype。
apply_window_levelArrayLike，width、center、output_min、output_max。float32 ndarray；width 必须 > 0，output_max 必须 > output_min。
resample_volumeArrayLike，source_spacing、target_spacing、interpolator、default_value。ndarray；仅 nearest、linear、bspline。
array 使用 (z,y,x)，spacing 使用 (slice,row,column)。mask/label 使用 interpolator="nearest"。压缩传输语法需要 pydicom 可用的像素解码插件。

推荐处理顺序

pixels = read_series(ordered_paths)
spacing = get_spacing(ordered_paths)
pixels = apply_monochrome(pixels, "MONOCHROME1")
pixels = apply_window_level(pixels, 400, 40)
pixels = resample_volume(pixels, spacing, (1.0, 1.0, 1.0))
read_series要求调用方已经完成 Series 选择和文件排序；空列表、缺失文件、混合 Series 或几何不一致会抛出异常。
apply_window_level使用 DICOM C.11.2 线性窗公式并映射到 [output_min, output_max]。
resample_volume使用 SciPy 的 nearest、linear 或 cubic B-spline 插值，并按物理范围计算新 shape。

边界

Gray 不提供通用 Web、模型、Dataset、loss、推理服务、患者 metadata 策略、Series 选择、DICOM 编码、临床标签规则。项目级语义必须留在项目仓库。
